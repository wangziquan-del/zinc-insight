# 锌息相关

永安期货锌产业研究看板。版式沿用「锡息相关」，数据按以下优先级组装：

1. 直集（Zhiji）API：行情、库存、TC、产量、开工率、进出口与升贴水。
2. 永安期货锌数据库：产业链历史、利润、PMI、平衡表与项目梳理。
3. 全球锌企季度产量梳理：矿企、冶炼厂、资本开支与更新日志。
4. StoneX 2026 年 5 月表：全球供需预测、季度平衡与国别拆分。

本地构建：

```powershell
python scripts\build_site.py
```

构建会读取本机四份 Excel/XLS 源文件，并优先用直集 API 覆盖可获得的最新数据。线上版本由 GitHub Actions 定时刷新直集数据，不在前端暴露 API Key。

访问口令与参考站一致。页面口令是客户端访问门，不应视为服务器级权限控制。
